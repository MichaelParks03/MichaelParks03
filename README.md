## Projects

**[BuildBetter](https://github.com/MichaelParks03/buildbetter)**
Paste your PC specs, pick a budget and a use case, get a measured bottleneck analysis and an upgrade plan you can actually buy. Scores every CPU and GPU against a bundled benchmark dataset, respects socket and RAM generation compatibility, and tells you honestly when your budget is too small to help. React, Vite, Tailwind, Netlify Functions, Node.

**[Mimi's Paws](https://mimispaws.com)**
Live booking site for a pet care business. Multi visit cart scheduling, pet intake forms, and an owner side accept or reject flow that hands the owner a ready to send confirmation. React, Supabase, Postgres, Netlify.

**[Life Dashboard](https://github.com/MichaelParks03/MoneyManagementDashboard)**
One dashboard for the things I actually track: finances, investments, meals, workouts, and calendar. Every module writes to a shared data layer, so a logged workout and a logged meal land in the same weekly view instead of in two apps that do not know about each other. Built because the alternative was six apps and no way to see a week at once. [Stack.]

## How I build

Database functions get tested live against the real database before I write any frontend. Row level security is closed by default and opened deliberately, per table. Passcodes are hashed, endpoints are rate limited, and secrets never reach client code.

I would rather a project be correct at the edges than look finished. BuildBetter's planner refuses to recommend an upgrade when the budget cannot buy a meaningful one, because the alternative is telling someone to waste their money.
